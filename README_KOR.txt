KoreanAIR_AC8_ModPack_1.4
한국어 사용 안내

설치와 실행

1. 먼저 Steam에서 ACE COMBAT 8을 한 번 정상 실행한 뒤 게임을 종료하세요.
2. ZIP 전체를 압축 해제하고 Payload.zip과 같은 폴더의
   KoreanAIR_AC8_ModPack_1.4_Setup.exe를 실행하세요. start_protected_game.exe가
   있는 게임 폴더를 지정하고 모듈을 선택한 뒤 설치 / 업데이트를 누르세요.
3. 게임 폴더의 KoreanAIR_AC8_ModPack_1.4.exe를 실행하세요. Steam을 켜 둔 상태로
   선택한 모드로 실행을 누르세요.

설치 프로그램만 받은 경우에는 필요한 모드 파일을 검증하여 내려받습니다.

모듈 설치·제거·변경 전에는 게임을 종료하세요. 쓰기 가능한 Steam 라이브러리에는
관리자 권한이 필요하지 않습니다. 보호된 폴더는 설치 프로그램을 관리자 권한으로
실행해야 할 수 있습니다. 지원하는 게임 실행 파일은 타임스탬프 0x6AA0E27D,
이미지 크기 0x2195A000입니다. 지원하지 않는 게임 업데이트는 설치·실행이 거부됩니다.

설치된 런처에 업데이트 배너가 없다면 제거하지 말고 최신 설치 프로그램을 한 번
실행하세요. 기존 설정은 유지됩니다.

다른 모드가 Game/Binaries/Win64/dinput8.dll을 사용하면 파일 변경 전에 안내합니다.
예를 선택하면 캠페인 한국어 자막을 제외하고 설치하며, 기존 로더와 다른 모드 파일을
보존합니다. 선택한 마우스 조종과 화면 기능은 계속 사용할 수 있습니다. 나중에 캠페인
한국어 자막을 추가하려면 충돌하는 로더를 직접 제거한 뒤 런처의 설치 탭에서 설치
모듈 변경을 선택하세요. 다른 모드와의 실제 게임 내 동시 사용은 검증되지 않았습니다.

업데이트

런처를 열 때마다 자동으로 업데이트를 확인하며, 새 업데이트가 있으면 상단의 눈에
잘 띄는 배너로 안내합니다. 게임을 종료한 뒤 지금 업데이트를 누르세요. 업데이트를
다운로드하고 검증한 뒤 적용하고 런처를 다시 시작합니다. 표시되는 버전 번호가 같아도
새로운 오류 수정 빌드가 있을 수 있으며, 이런 업데이트도 배너로 안내합니다.

선택한 모듈과 저장된 INI 설정, 조종과 단축키, HUD와 조준선, 조준 방향 확대,
FOV와 카메라 설정, 프레임 생성 선택, 자막 위치와 표시 언어를 유지합니다. 기본 플레이를 위해
모드팩을 꺼 둔 상태라면
업데이트 후에도 꺼진 상태를 유지합니다. 인터넷이 연결되지 않거나 업데이트 확인·
다운로드에 실패해도 런처에서 설치된 모드로 계속 플레이할 수 있습니다.

모듈 구성

- 한국어 캠페인 자막: 영어 원문을 바탕으로 캠페인 한국어 자막을 개선합니다.
  온라인 대사는 변경하지 않습니다.
- 마우스 조종: 마우스 비행 조종, Alt 자유 시점, 누를 때마다 전환하는 조준 방향 확대,
  비행 보조 HUD를 제공합니다.
- 트리플 모니터와 FOV: 단일 화면 비행 FOV 또는 세 화면에 걸친 창을 지원합니다.
  마우스 조종도 설치하면 추적 카메라 거리와 높이를 조정할 수 있습니다.

값 조정 방법

숫자 설정에는 슬라이더와 숫자 입력란이 함께 있습니다. 슬라이더를 끌어 빠르게
조절하거나, 슬라이더에 포커스를 둔 뒤 좌우 방향키를 누르세요. 정확한 값은 숫자
입력란을 눌러 직접 입력하거나 위아래 화살표로 조정하세요. 두 조작부는 같은 값을
표시하며, 화면에 표시된 허용 범위 안에서 설정할 수 있습니다.
미세 조절 단위는 감도 0.001, 확대 배율 0.01배, FOV 0.1도, 카메라 거리·높이 1입니다.
해당 탭의 저장 버튼을 눌러야 변경한 값이 저장됩니다.

마우스 조종 (조종 / Controls)

마우스 조종 감도와 자유 시점 감도를 각각 조절할 수 있습니다.
비행 중 자유 시점 키를 누르고 있으면 주변을 볼 수 있습니다. WASD 직접 조종도
유지됩니다. 저장한 뒤 게임 화면에 포커스를 두면 감도·확대·모드 단축키 설정이
약 0.5초 안에 자동으로 적용됩니다. F10은 수동으로 다시 읽을 때 쓰는 선택 사항이며,
저장한 설정을 적용하기 위해 누를 필요는 없습니다.

조준 방향 확대는 기본으로 켜져 있습니다. 일반 비행 중 마우스 오른쪽 버튼을
한 번 누르면 마우스 조종 목표 방향으로 카메라를 돌려 화면을 확대하고,
다시 누르면 일반 비행 카메라로 돌아옵니다. 확대와 복귀는 140ms 동안 부드럽게
전환됩니다. 버튼을 놓아도 확대 상태가 유지됩니다. 잠긴 타겟을 선택하는 기능은
아닙니다. 조종 탭의 조준 방향 확대
사용으로 기능을 켜거나 끄세요. 조준 방향 확대 배율은 슬라이더나 숫자 입력란에서
1~8배 범위로 0.01배씩 조절할 수 있으며, 기본값은 2배입니다. 확대 키는 키보드 키
또는 마우스 오른쪽·가운데·옆 버튼으로 바꿀 수 있습니다. 확대 중 Alt를 누르고
있으면 같은 배율로 주변을 볼 수 있습니다. Alt를 놓으면 확대를 유지한 채 마우스
조종 목표 방향으로 부드럽게 돌아옵니다. Alt 자유 시점 중에도 확대 버튼을 다시
누르면 일반 배율로 돌아옵니다. 메뉴·시네마틱에서는 확대가 해제되므로 일반
비행으로 돌아온 뒤 다시 클릭해 확대하세요.
마우스 조종 모듈이 필요하며, 화면·카메라 설정을
꺼도 사용할 수 있습니다. 타겟 보기·자유 시점·시네마틱의 카메라 동작은 유지됩니다.
같은 버튼에 지정한 게임 기능도 반응한다면 게임의 조작 설정에서 해당 단축키를
변경하세요. 조종·키 설정 저장을 누르면 F10 없이 확대 설정도 자동으로 적용됩니다.

게임의 시점 전환키로 1인칭·조종석·3인칭을 전환하세요. 1인칭과 조종석에서는
게임의 원래 카메라 위치와 롤을 유지합니다. 추적 카메라 거리·높이는 3인칭에만
적용됩니다.

게임의 타겟 선택 버튼을 짧게 눌렀다 놓으면 마우스 조종 원의 중심에 가장 가까운
화면상의 타겟 후보를 선택합니다. 원 안에 들어와야만 선택되는 것은 아닙니다.
화면 밖이나 카메라 뒤쪽의 타겟은 제외하며, 선택 가능한 후보는 게임 자체의
타겟 후보 목록을 따릅니다. 0.35초 이상 누르고 있으면 게임의 타겟 보기 기능이
유지됩니다.

코브라·쿨비트 등 특수 기동은 게임 자체의 기종·발동 조건을 그대로 따릅니다.
게임의 특수 기동 회전 중에는 일반 마우스 추종이 원래 기동 조종에 맡겨집니다.
직접 누른 키보드 조종축은 원래 입력을 유지하며, 마우스 상승 입력도 게임의
기동 입력에 맞춰 처리합니다. 기동 회전이 끝나면 일반 마우스 추종이 재개됩니다.
일반 비행에서는 키보드 피치와 마우스 좌우 조종을 함께 사용할 수 있습니다.
급선회를 위해 가속·감속을 동시에 누르는 것만으로 마우스 추종이 꺼지지 않습니다.

인터랙티브 장면의 마우스 시점

원래 7/8/9/0으로 고개나 카메라를 움직이던 장면 중 시점 조작이 가능한 지원
장면에서는 마우스로 주변을 볼 수 있습니다. ALT를 누를 필요는 없습니다.
감도는 조종 탭의 자유 시점 감도를 사용하며, 비행 중 ALT 시점과 동일합니다.
기존 키보드 시점 조작과 게임의 장면별 회전 제한은 유지됩니다. 이때 마우스
움직임은 비행 조종 목표에 반영되지 않습니다.

모드 기본 단축키 (조종 탭에서 변경 가능):
- F7: 비행 보조 HUD 표시 / 숨기기
- F8: 마우스 조종 켜기 / 끄기
- F9: 마우스 조종 중심 재설정
- F10: 저장한 조종 설정 다시 읽기
- Alt를 누르고 있기: 자유 시점
- 마우스 오른쪽 버튼 한 번 누르기: 조준 방향 확대, 기본 2배 / 다시 누르기: 복귀

목록에서 키를 선택하거나 키 입력 버튼으로 지정하세요. 확대에는 마우스 오른쪽·
가운데·옆 버튼도 지정할 수 있습니다. 여섯 모드 기능마다 서로 다른 키를 사용해야
합니다. WASD/QE·Esc·Enter·Tab·Windows 키는 지정할 수 없습니다.
게임의 다른 단축키와도 겹치지 않게 설정하세요.
게임 자체의 비행 조종키와 타겟 선택키는 게임의 조작 설정에서 변경하세요.

크로스헤어 (크로스헤어 / Crosshairs)

마우스 조종에는 계단 현상을 줄인 두 가지 표시가 있습니다. 마우스로 지정한 조종
목표와 기체의 기수 방향입니다. 마우스 조종 목표는 항상 원이며, 게임 창이 걸쳐
있는 모니터의 주사율에 맞춰 새 마우스 입력을 표시합니다. 두 표시의 크기와 색상은
각각 조절할 수 있습니다. 모양 선택은 기수 방향 표시에만 적용되며,
원, 십자 + 점, X, 십자, 원 + 십자 중에서 선택하세요. 선 두께, 얇은 테두리
표시 여부, 불투명도는 두 표시에 공통으로 적용됩니다. 색상은 FFFFFF 또는
#00FF80 같은 RGB 6자리 값으로 입력하거나 색 선택 버튼으로 지정하세요.
실제 전투기의 조준 기호를 참고한 디자인이며 특정 기종의 무장 조준 장치를
재현하는 기능은 아닙니다. 기수 표시는 방향을 나타내며, 기총의 선행 조준점이나
게임 자체의 무장 조준 해법을 나타내지 않습니다.

플레이 중에도 조준선 설정을 저장한 뒤 게임 화면에 포커스를 두면 약 0.5초 안에
자동으로 적용됩니다. 재시작은 필요하지 않습니다. HUD 단축키로 두 표시를
함께 숨기거나 표시할 수 있습니다.

화면과 카메라 (화면·카메라 / Screen & camera)

카메라 설정 사용을 켜면 이 탭의 카메라 옵션이 적용됩니다. FOV는 16:9 기준이며
비행 중에만 적용됩니다. 메뉴와 미리 제작된 동영상은 원래 화면을 유지합니다.
추적 카메라 거리와 높이는 마우스 조종 모듈이 있어야 사용할 수 있으며,
3인칭에만 적용됩니다.

트리플 화면에는 픽셀 해상도가 같은 모니터 세 대가 필요합니다. Windows 디스플레이
설정에서 왼쪽 / 주 화면 / 오른쪽 순서로 바로 붙여 배치하세요. 가운데 모니터를
주 디스플레이로 지정하고, 세 화면의 위쪽을 같은 높이로 맞춰야 합니다.
NVIDIA Surround는 필요하지 않습니다. 배치가 맞지 않으면 트리플 화면 옵션을
사용할 수 없지만 단일 화면 FOV는 사용할 수 있습니다.
변경 사항을 저장한 뒤 게임 화면에 포커스를 두면 적용 결과를 볼 수 있습니다.

트리플 화면을 켜면 지원하는 실시간 렌더링 시네마틱, T 타겟 보기 장면과
인터랙티브 고개 조작 장면도 세 화면에 걸쳐 표시합니다. 원래 카메라 이동과
줌 연출을 유지하며 좌우 시야를 확장합니다. 비행 FOV 슬라이더가 시네마틱의
줌 연출을 대체하지는 않습니다. 현재 카메라를 확인할 수 있고 실제 렌더 크기가
확장된 화면 크기와 일치해야 적용됩니다. 확인할 수 없는 카메라, 미리 제작된
동영상, 별도 화면 요소로 그려진 검은 바는 변경하지 않습니다.

프레임 생성 (프레임 생성 / Frame generation)

저장한 설정 파일은 런처가 관리하는 동안 보호합니다. 원래 설정 복원을 누르면
원래 내용과 파일 속성으로 돌아갑니다.

게임을 종료한 뒤 프레임 생성 탭에서 켜기 또는 끄기를 선택하고 프레임 생성
저장을 누르세요. 저장한 선택은 다음 게임 실행부터 적용되며, 변경할 때마다
게임을 다시 시작해야 합니다. 게임 실행 중에는 변경할 수 없습니다. 모드팩을
꺼 둔 경우에는 모드 다시 사용을 선택한 뒤 저장하세요.

처음에는 기존 게임 설정을 그대로 사용하며, 업데이트도 저장한 선택을 유지합니다.
원래 설정 복원을 누르면 이 모드의 프레임 생성 지정을 해제하고 게임의 원래
설정을 사용합니다. 켜기를 저장해도 게임, 그래픽카드와 드라이버가 지원하지
않으면 프레임 생성이 활성화되지 않을 수 있습니다. 저장한 선택만으로 실제
활성화 여부나 프레임 속도 향상이 확인되는 것은 아닙니다.

일반 DLSS, 그래픽 품질, 프레임 제한, VSync 등은 게임 안의 그래픽 설정에서
조절하세요. 런처의 프레임 생성 탭은 프레임 생성 켜기·끄기만 제공합니다.

자막 위치 (자막 / Subtitles)

원래 위치를 선택하면 게임의 대사 자막 배치를 유지합니다. 화면 하단을 선택하면
지원하는 비행 중 무전 대사와 시네마틱 대사 자막을 아래로 내립니다. 자막 위치
저장을 누른 뒤 게임 화면에 포커스를 두세요. 플레이 중에도 자동으로 적용됩니다.
모듈을 하나 이상 설치하면 사용할 수 있으며, 한국어 캠페인 자막 번역과 별개의
설정입니다. 제목, 크레딧과 다른 HUD 요소는 원래 위치를 유지합니다.

일반 실행과 온라인 플레이

모드 런처는 게임의 오프라인 Null-client 설정을 사용합니다. 모듈은 오프라인
플레이용입니다. 일반 실행 또는 온라인 플레이 전에는 게임을 종료하고 플레이 탭에서
기본·온라인 플레이용 모드 끄기를 선택한 뒤 Steam에서 게임을 정상 실행하세요.
이 기능은 이 모드팩의 로더와 자막 아카이브를 활성 게임 경로 밖으로 옮깁니다.
온라인 플레이 전 다른 모드의 상태도 직접 확인하세요. 모드 다시 사용을 누르면
이 모드팩을 오프라인 플레이용으로 다시 사용할 수 있습니다.

모듈 변경, 제거와 백업

설치 탭의 설치 모듈 변경을 누르면 설치 프로그램이 열립니다. 여기에서 제거를
누르거나, 모든 모듈 선택을 해제한 뒤 설치 / 업데이트를 누르면 모드팩이 제거됩니다.
이 모드팩이 기록한 파일만 제거·복원하며, 저장 데이터와 관련 없는 파일은 보존됩니다.
외부에서 변경한 프로그램 파일이 발견되면 제거를 중단하고 해당 파일을 보존합니다.
